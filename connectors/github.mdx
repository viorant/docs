title: "GitHub"

---

The GitHub remote MCP server lets your skills and agents work with repositories,
issues, and pull requests. Connect it with your own GitHub OAuth app.

Connector URL: `https://api.githubcopilot.com/mcp`

<Note>
  Your Client Secret is stored in your **OS credential store** — Keychain on macOS,
  Credential Manager on Windows — and is **never sent to Viorant's servers**. See
  [Bring your own OAuth app](/connectors/oauth-apps) for the general flow.
</Note>

## Create the OAuth app

<Steps>
  <Step title="Open your OAuth apps">
    In GitHub, go to **Settings → Developer settings → OAuth Apps** and click **New
    OAuth App**.
  </Step>
  <Step title="Set the callback URL">
    Give the app a name and a homepage URL. For **Authorization callback URL**, paste:

    ```
    https://api.viorant.ai/oauth/connector/callback
    ```

    That is the production redirect. `vio connect` prints the URL it will actually
    send, under "Add this exact URL to the provider's Authorized redirect URIs:".
    The printed line matches the URL above unless this machine's `control_url` is
    overridden. The Hub shows the same URL in connector setup.
  </Step>
  <Step title="Get the credentials">
    Register the app, then copy the **Client ID** and generate a **Client Secret**.
  </Step>
</Steps>

<Note>
  GitHub OAuth apps don't set scopes up front — you approve the access the connector
  requests when you sign in. When the bundle does not declare `requires[].scopes`,
  `vio connect` asks for `repo`. GitHub has no read-only form of that scope. Org or
  team tools need `read:org`, which you add on the bundle's `requires[].scopes` (or
  pass with `--scopes`).
</Note>

<Warning>
  If the OAuth app is owned by a GitHub organization, the organization can require
  an org owner to approve it before anyone else can authorize it. Until that
  approval, sign-in fails even when the client id and secret are right.
</Warning>

## Connect in the Hub

<Steps>
  <Step title="Add the connector">
    Add a connector with the URL `https://api.githubcopilot.com/mcp`.
  </Step>
  <Step title="Paste your credentials and connect">
    Enter your **Client ID** and **Client Secret**, click **Connect**, and approve
    access in your browser.
  </Step>
</Steps>

## From the CLI

Add these to `.vio/.env.connectors`, then run `vio connect`. Leave the secret out of
`agent.vio`.

```
GITHUB_OAUTH_CLIENT_ID=
GITHUB_OAUTH_CLIENT_SECRET=
```

`vio docs connectors github` prints this guide. `vio connectors github` and the
`vio connect` prompt point here.
